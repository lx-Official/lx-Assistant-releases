# 落雪助手发行包

[下载最新安装包](https://github.com/lx-Official/lx-Assistant-releases/releases/latest)

本仓库只提供安装包及签名更新清单，不存放助手源码、用户卡密或用户数据。

首次安装请选择与服务器平台匹配的完整安装包。安装带在线更新启动器的版本后，点击助手右上角头像菜单中的“检测更新”，确认后由助手自行下载、校验并切换核心。配置和卡密继续保留；启动失败会回退旧核心。

以 snowfall-core 开头的文件由程序自动下载，不要手工导入。首次安装步骤见安装包中的中文说明。

框架卡片显示启动器安装包版本，助手界面显示实际核心版本。
